# Guilds System

A browser-based roguelite prototype: pull heroes and one-run Champions across an F-S rank ladder, assemble a party, and push through Rifts for Coins, Crystals, and Seal Tokens.

**Play:** open `index.html` (or the GitHub Pages link) in any browser. Progress autosaves to your browser's local storage, so each player keeps their own separate save.

**Reference:** `compendium.html` — full list of classes, skill trees, relics, monsters, and upgrades. Linked from the in-game topbar.

This is a test build — feedback welcome.
